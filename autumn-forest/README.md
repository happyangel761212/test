# 단풍과 은행나무 숲 (가을 숲 라인아트 애니메이션)

단풍나무와 은행나무가 가득한 가을 숲길을 한 자루 잉크 펜 느낌으로 그린 SVG 애니메이션 컴포넌트입니다.
[JDhruv14/line-art-animation](https://github.com/JDhruv14/line-art-animation) (MIT)의 라이브러리(`lib/`)와 스타일 규칙을 따릅니다.

## 바로 보기
`dist/autumn-forest.html` 을 브라우저로 열면 됩니다 (단일 파일, 외부 의존성 없음).

## 장면 구성
- 앞줄/뒷줄의 은행나무(불꽃꼴 노란 수관)와 단풍나무(둥근 지붕꼴 붉은·주황 수관), 왼쪽 위 단풍 가지
- 바람에 팔랑이며 떨어지는 단풍잎·은행잎 → 길과 둑에 쌓이고, 개울에 떨어진 잎은 떠내려감
- 산책하는 사람(베레모·토트백), 지팡이 짚은 할아버지, 뛰어노는 아이, 줄무늬 다람쥐, 까치, 기러기 떼, 억새
- 먼 산 능선의 단풍 점묘와 언덕 위 정자, 징검다리 개울, 벤치와 가로등
- 하루 160초 주기의 밤낮 순환 (밤에는 잉크가 반전되고 가로등·정자 불빛이 켜짐)

## 상호작용
| 대상 | 반응 |
|---|---|
| 포인터 이동 | 바람 (세게 휘저으면 쌓인 잎이 굴러감) |
| 해/달 드래그 | 시간 변경 |
| 나무·가지 클릭 | 흔들리며 잎이 쏟아짐 |
| 사람 클릭 | 멈춰서 올려다보고 손을 뻗음 / 할아버지는 지팡이에 기대 올려다봄 / 아이는 깡충 뛰며 낙엽을 차올림 |
| 다람쥐·까치 클릭 | 달아났다가 잠시 뒤 돌아옴 |
| 물 클릭 | 물결, 떠 있던 잎이 밀려남 |
| 하늘 클릭 | 기러기 떼 |

`?debug` 를 붙이면 rAF 대신 `window.__step(초)` 로 프레임 단위 확인이 가능합니다.

## 빌드
```bash
npm i esbuild            # 아무 폴더에나
node build.mjs <esbuild가 설치된 폴더>   # → dist/autumn-forest.html
```
